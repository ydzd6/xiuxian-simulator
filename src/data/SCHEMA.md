# 事件数据规范（写内容前必读）

所有事件数据都是**纯数据**（可 JSON 序列化），不能出现函数、正则、模板字符串、`undefined`、注释以外的 JS 语法。
每个文件是一个 ES 模块：`export const EVENTS_XXX = [ ... ];`

## 运行时状态字段（写条件与效果时只能用这些）

```
name        姓名(string)
gender      "男" | "女"
origin      出身(string)         例如 "山村孤儿"
root        灵根(string)         例如 "天灵根"
rootMult    灵根倍率(number)
realm       境界索引(number)
            0 凡体 / 1 炼气 / 2 筑基 / 3 金丹 / 4 元婴 / 5 化神 / 6 渡劫 / 7 飞升
cult        当前修为(number)     突破下一境界所需阈值见下
age         岁数(number)
lifespan    寿元上限(number)     凡体 80 / 炼气 120 / 筑基 200 / 金丹 400 / 元婴 800 / 化神 1500 / 渡劫 3000
luck        气运(number)         0~100，越大越容易撞见好事
mind        道心(number)         0~100，越高压制心魔、突破越稳
mo          魔念(number)         0~100，越高越容易堕入魔道
fame        声望(number)         0~1000
wealth      灵石(number)         可为负（欠债/被抢）
sect        宗门(string|null)
contribution 宗门贡献(number)
flags       标签集合(string[])
turn        当前回合数(number)   第 1 回合是第一件事
rels        人物好感 { [姓名]: number }   0~100
partner     道侣姓名(string|null)
```

突破阈值（从当前境界突破到下一境界所需修为）：`60 / 180 / 450 / 1000 / 2000 / 3600 / 6000`

## 事件对象

```js
{
  id: "d02_07",              // 全局唯一，用你自己文件的前缀
  title: "藏经阁的深夜",       // 4~10 字
  weight: 10,                // 抽取权重，默认 10。越大越常出现，普通事件 8~12，稀有 3~5
  once: true,                // 是否只出现一次，默认 true
  cond: { realmMin: 1, realmMax: 3 },   // 出现条件，全部满足才可能被抽到；可写 {}
  text: "……事件正文……",      // 约 50 字（42~52），第二人称「你」；只写一个有画面感的场景 + 一个往下选的钩子
  choices: [
    {
      text: "推门进去",        // 按钮文字，6~14 字
      effect: { cult: 40, luck: 5, flagAdd: ["夜读残卷"] },
      result: "……结果描写……"  // 60~140 字
    }
  ]
}
```

### cond 可用字段（全部可选，同时满足才成立）

```
realmMin / realmMax      境界索引范围
sect: ["青云剑宗", "丹霞谷"]   当前宗门属于其中之一；写 "无" 表示没有宗门
noSect: true             等价于 sect: ["无"]
gender: "男" / "女"
luckMin / luckMax        气运范围
mindMin / mindMax        道心范围
moMin / moMax            魔念范围
fameMin / fameMax        声望范围
ageMin / ageMax          岁数范围
cultMin                  修为下限
flagAll: ["a","b"]       必须全部拥有
flagAny: ["a","b"]       至少拥有一个
flagNone: ["a"]          必须没有
turnMin / turnMax        回合数范围
chance: 0.4              额外概率门槛（0~1）
```

### effect 可用字段（全部可选）

```
cult, luck, mind, mo, fame, wealth, lifespan, contribution   数值增减（可负）
age            本回合额外推进的岁数（不写则随机推进 2~5 岁）
flagAdd / flagDel   string[]
sectJoin       加入该宗门（字符串）
sectLeave      true 表示叛出/离开宗门
partner        设置道侣姓名
rel            { "苏婉儿": 15 }   人物好感增减
realm          直接改变境界（慎用，只用于"一夜筑基"这类剧情）
death          "一句话死因"     触发了就直接进入陨落结局，慎用，每个文件最多 2 个
log            "年表上的一行字"  15 字以内，会出现在结局的生平年表里（重要选择请写）
```

## 硬性要求

1. `id` 用你文件的前缀 + 两位序号，例如 `d02_01` ~ `d02_28`，不许重复、不许跳号。
2. 每个事件 **2~4 个选项**，选项之间必须是真正的取舍（不是换个说法的同一件事）。
3. **不提示后果**：`text` 里不要剧透，选项中不要写"（危险）""（安全）"。
4. 数值范围参考：普通事件属性变化在 ±3~10；`cult` 在 20~260；`wealth` 在 ±200 内；`mo` 一次最多 +15；`death` 只在真正凶险的选项上给，且必须至少留一条活路。
5. 事件必须有逻辑：选项 → 结果必须因果自洽，不能"选什么都一样"。
6. 文风：正经仙侠打底，偶尔一句冷幽默（不要网络烂梗、不要 emoji）。第二人称。
7. 感情线含蓄克制，不出现亲密描写、不涉黄涉政。
8. 不能出现现实世界的品牌、人名、地名。

## 境界与宗门背景（保持一致）

宗门六家：

- **青云剑宗** —— 剑修，刚直，护短，宗门大比最狠
- **丹霞谷** —— 丹修，温吞，富庶，擅长救人与毒
- **天音阁** —— 音修，弟子多情，擅长幻术与疗心
- **万魔殿** —— 魔道，弱肉强食，修为涨得最快
- **散修联盟** —— 无宗门的散修互助会，自由但没靠山
- **合欢宗** —— 双修合道，讲究情之所至道之所生，表面轻浮实则最重诺（写法务必含蓄）

固定人物（跨文件复用，务必用同一套名字与性格）：

- **苏婉儿** —— 小师妹，灵动嘴甜，爱吃，遇事却极硬气
- **沈青霜** —— 清冷师姐，剑修，寡言，外冷内热
- **顾长歌** —— 同门师兄，洒脱爱笑，嘴上不正经
- **江晚舟** —— 药庐少年，温润安静，命途多舛（男性角色）
- **姜雪璃** —— 万魔殿圣女，危险而赤诚
- **白芷** —— 丹霞谷药女，倔强，与你有旧恩
- **玄虚道人** —— 你可能的师尊，邋遢老道，深不可测
- **血煞老祖** —— 反派，血煞门之主
- **罗睺** —— 万魔殿魔道大能，行事无常

玩家性别有男有女，涉及恋爱的事件要用 `cond.gender` 区分，或写成不依赖性别的写法。
